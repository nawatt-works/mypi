# Persistent Todo + Handoff Extension

## สถานะ

รอคุยรายละเอียดภายหลัง ยังไม่เริ่มพัฒนา

## แนวคิด

เขียน Pi extension เพียงตัวเดียวที่รวมความสามารถของ:

- **Todo** — ติดตามงานที่กำลังทำ งานที่เสร็จแล้ว และงานถัดไป
- **Handoff** — บันทึกบริบทสำคัญลง workspace เพื่อให้เปิด session ใหม่แล้วทำงานต่อได้

เป้าหมายหลักคือป้องกันการสูญเสียสถานะเมื่อต้องเริ่ม session ใหม่เพราะ context window มีขนาดใหญ่เกินไป

## ประเด็นที่ต้องคุยก่อนลงมือ

- รูปแบบและตำแหน่งไฟล์สำหรับเก็บสถานะ
- ข้อมูลที่ต้องส่งต่อไปยัง session ใหม่
- จะบันทึกอัตโนมัติหรือใช้คำสั่งให้บันทึก
- วิธีโหลดและใส่ handoff เข้า context
- UI และคำสั่งที่ต้องการ เช่น `/todo`, `/handoff`, `/resume`
- ช่วงเวลาที่ Todo ควรปรากฏหรือถูกซ่อน
- วิธีจัดการหลาย session ที่ทำงานใน workspace เดียวกัน
- เงื่อนไขการล้างหรือเก็บประวัติ handoff
